# 移动光源(MoveLight)

手上拿着会发光的东西，跟着你走 —— 脚下和身边自动亮起来，把手里的东西换掉就灭。

纯客户端模组，**单人存档和联机都能用**，服务端不用装。

适用于 Minecraft **26.4-snapshot-5** / Fabric。

## 下载

到 [Releases](https://github.com/2006522/movelight/releases) 页面下载最新的
`MoveLight-<版本号>.jar`。

## 安装

1. 先装好 **Fabric Loader**（0.19.5 或更新）和 **Fabric API**
2. 把 `MoveLight-<版本号>.jar` 丢进 `.minecraft/mods/`
3. 启动游戏

没有配置文件也能直接用，默认行为就是"拿着火把走路会亮"。

## 用法

什么都不用按。主手或副手拿着会发光的东西，身边就自动亮；换掉或收起就灭。

| 手上拿的东西 | 亮度 |
| --- | --- |
| 荧石、海晶灯、南瓜灯、蛙明灯、营火 | 15 |
| 红石灯（不管亮没亮）、岩浆桶 | 15 |
| 火把、灯笼、末地烛 | 14 ~ 15 |
| 蜡烛（不管点没点） | 12 |
| 萤石粉、烈焰棒 | 7 |
| 烈焰粉 | 6 |
| 发光墨囊、岩浆膏 | 5 |
| 其它会发光的方块 | 跟它亮着的时候一样亮 |

方块类物品取的是它**所有状态里的最高亮度**，所以红石灯、蜡烛这种默认是灭的方块，
拿在手上也会亮。

主副手同时拿着发光的东西时，取**亮的那一个**。

## 配置

配置文件在 `.minecraft/config/movelight.properties`，第一次启动会自动生成。

```properties
# 总开关
enable=true

# 亮度倍率，0.5 就是 15 格光压成 7 格
brightness_scale=1.0

# 光源相对玩家的偏移（格），一般不用改
offset_x=0.0
offset_y=0.0
offset_z=0.0

# 往下找能放光的空格（站在台阶上时有用）
snap_to_ground=true

# 不算方块但也要发光的物品，格式 物品id=亮度
extra_items=minecraft:lava_bucket=15,minecraft:glowstone_dust=7,...
```

改完文件重启游戏生效。

- 想让所有光都暗一点：`brightness_scale=0.7`
- 想加自己的模组物品：往 `extra_items` 里追加 `你的模组id:物品id=亮度`
- 觉得光源位置偏了（比如骑马时光在身后）：微调 `offset_z`

## 环境要求

- Minecraft **26.4-snapshot-5**
- Fabric Loader **0.19.5** 或更新
- Fabric API
- Java **25**

## 已知限制

- **创造模式物品栏里换物品测不出来**：创造模式物品栏开着的时候，手里那份"物品"
  只是界面上的虚拟物品，模组看到的一直是背包里真正拿着的那格，所以不会跟着变。
  关掉界面就正常。
- **水里不亮**。光源方块塞进流体会在客户端挖出一个水洞，看着比不亮更难受，
  所以水下直接不发光。
- **上岸/钻洞时会闪一格**。光源跟着脚走，跨格子的那一瞬间会先撤旧的再放新的，
  如果那一格正好被方块占着，光会短暂消失一个 tick。
- **只影响自己看到的画面**，联机时别人看不到你的光（这是纯客户端实现的必然结果）。
- 装光影（Iris / OptiFine shader）时，方块光由光影自己算，可能不跟着变。
